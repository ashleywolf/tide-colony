# 🏝️ Tide Colony

An ONI-inspired colony simulation game set on a tropical island with dynamic tidal mechanics. Built with vanilla JavaScript and HTML5 Canvas.

## Play

Open `index.html` in a browser. No build step required.

## Controls

| Key | Action |
|-----|--------|
| **WASD** / **Arrow Keys** | Pan camera |
| **Scroll wheel** | Zoom in/out |
| **Left click** | Place building / Select islander |
| **Right click** | Dig tile |
| **1-5** | Select building type |
| **Space** | Pause/resume |
| **T** | Toggle tide overlay |

## Mechanics

- **Tides** rise and fall on a cycle, flooding low-lying areas
- **Islanders** have needs: hunger, thirst, and rest
- **Buildings** require resources: coral, driftwood, coconuts
- **Water** flows downhill and fills cavities realistically
- **Seawalls** block water — build above the tide line or defend your base
